# souravbhadra.com

Personal portfolio site for Sourav Bhadra, Ph.D. — a data scientist working
in AI, computer vision, and geospatial machine learning.

Built with [Astro](https://astro.build), Tailwind CSS, and TypeScript. All
content lives in `data/site.ts`; the color theme is set in `src/config.ts`.

## Develop

```bash
npm install
npm run dev      # local dev server
npm run build    # static build → dist/
npm run preview  # preview the build
npm run check    # type-check
```
